# tiny-bmp-editor

## 개요
**tiny-bmp-editor** 는 C#과 WPF를 활용해 제작된 가벼운 BMP 이미지 편집기입니다.

심플하고 직관적인 그래픽 인터페이스를 통해 BMP(Bitmap) 파일을 열고 수정할 수 있습니다.

이 프로젝트는 **2023년**, **BMP 이미지 압축 알고리즘**을 학습하기 위한 **학습용 프로젝트**로 개발되었으며, 특히 **8비트 RLE(RLE8) 압축 포맷** 구현에 중점을 두었습니다.

## 주요 기능
- **BMP 이미지 파일** 열기 및 편집
- 지원 포맷:
  - **비압축 BMP (Uncompressed BMP)**
  - **8비트 RLE 압축 BMP (RLE8)**
- 모든 편집된 이미지는 **RLE8 압축 방식으로 저장**됨
- **WPF 기반 GUI** 제공
- 기본 편집 기능:
  - 흰색 사각형 그리기
  - 전체 이미지 색상 반전
- 변경 사항 실시간 미리보기

## 지원 플랫폼
- Windows (WPF 실행이 가능한 .NET 런타임 필요)

## 사용 기술
- C#
- Windows Presentation Foundation (WPF)

## 설치 방법
1. GitHub에서 저장소를 다운로드하거나 클론합니다.
```sh
git clone https://github.com/ChoHye0N/tiny-bmp-editor.git
```
2. **Visual Studio**에서 솔루션 파일을 엽니다.
3. 프로젝트를 빌드하고 실행합니다.

## 사용 방법
1. 애플리케이션을 실행합니다.
2. **파일 → 열기** 메뉴를 통해 BMP 파일(비압축 또는 RLE8)을 불러옵니다.
3. 제공되는 도구를 사용하여 이미지를 편집합니다:
   - 사각형 그리기
   - 밝기 반전
4. 편집된 이미지를 저장합니다.
   - 출력 파일은 자동으로 **RLE8 포맷으로 압축**되어 저장됩니다.

## 참고 사항
- 본 프로젝트는 BMP 파일 구조와 RLE 압축 방식을 이해하기 위한 **학습용**으로 제작되었습니다.
